================================================================================
TROUBLESHOOTING
================================================================================

If site doesn't load:
  1. Check PM2 status: pm2 status
  2. Check logs: pm2 logs elitpos
  3. Check Nginx: sudo systemctl status nginx
  4. Check database: psql "postgresql://..."

If build fails:
  1. Check Node.js version: node --version (should be 18+)
  2. Clear cache: rm -rf .next node_modules
  3. Reinstall: npm install
  4. Try again: npm run build

If database errors:
  1. Verify DATABASE_URL is correct
  2. Test connection: psql "postgresql://..."
  3. Check PostgreSQL status: sudo systemctl status postgresql
  4. Check logs: sudo tail -f /var/log/postgresql/*.log
